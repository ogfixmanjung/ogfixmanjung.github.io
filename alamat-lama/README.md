# Halaman pengalih untuk alamat lama

Fail dalam folder ini **bukan sebahagian daripada app**. Ia digunakan sekali sahaja
selepas repo dipindahkan ke organization `ogfixmanjung`.

Tujuan: link lama `https://asyrafwork54-oss.github.io/SYSTEM-TERIMA-DEVICE-OGFIX/...`
(termasuk link resit yang sudah dihantar kepada pelanggan) dibawa terus ke
`https://ogfixmanjung.github.io/...`.

## Cara guna
1. Di akaun peribadi GitHub, buat repo baru **public** bernama `SYSTEM-TERIMA-DEVICE-OGFIX`.
2. Upload 4 fail ini: `index.html`, `resit.html`, `404.html`, `sw.js`.
3. Settings → Pages → Branch `main`, folder `/ (root)` → Save.
